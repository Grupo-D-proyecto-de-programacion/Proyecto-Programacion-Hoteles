# Ocupación de los hoteles Sol Caribe

Trabajo de fin de curso de Fundamentos de Programación, Universidad del Magdalena. Alternativa A: un programa de consola en Python que lleva el registro diario de ocupación de los hoteles de la cadena Sol Caribe y calcula sus indicadores.

## Cómo ejecutar el programa

Desde la carpeta `codigo`:

```
python user_interface.py
```

En la opción 6 del menú, las rutas de los archivos de ejemplo se escriben así: `datos/hoteles.csv` y `datos/ocupacion.csv`, o `datos/hoteles_cadena.csv` y `datos/ocupacion_cadena.csv`.
